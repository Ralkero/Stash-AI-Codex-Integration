# Reviewed identity bindings and policy clarity

Auto-Tagger 0.9.27 separates user-reviewed identity meaning from permission to
assign a Tag to a particular scene. A local ID/name binding may recognize an
identity while its scene-association policy still blocks automatic additions.

Fictionalized female mascots are distinct from brands and their real inspirations.
Approved avatar, collective, shared-mantle and female-form identities have explicit
policy categories. Adult-performer verification and existing ignore preferences
are unchanged. Generic words, prior mislabels and model-generated guesses cannot
become authoritative association evidence.

The public integration delta deliberately excludes the private decision dataset,
library inventory, migration drafts and any runtime bundle containing those data.
No production metadata changes accompany this release. Renames, creation, merges,
title edits, assignment replacement and global deletion remain separate operations;
the bulk removal executor has not been broadened.

Validation covers public-owner regressions, private-policy fixtures, complete
installed read-result comparison, unchanged legacy Character/Descriptor contracts,
companion compatibility and database/state preservation. Private production reports
remain local. The existing isolated runtime home and conversation routing are not
modified.
